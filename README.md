# Light-wordpress-theme-starter


A Lightweight WordPress Starter Theme

A clean, high-performance starter theme designed to bypass the bloat of commercial page builders, built with core WordPress best practices.

Zero Bloat: Lightweight CSS structure focused on maximum Google Core Web Vitals performance.
Standards Compliant: Fully adheres to WordPress Coding Standards and PHP best practices.
Secure Enqueueing: Implements proper script and stylesheet loading via `functions.php`.
HTML5 & Responsive: Built with modern CSS custom properties (`:root` variables) and flexible grid/flexbox layouts.

 File Architecture
* `style.css` - Theme metadata and core design styles.
* `functions.php` - Theme setup, menu registration, and asset management.
* `header.php` - Standardized document head and navigation wrapper.
* `footer.php` - Closing site container and footer branding.
* `index.php` - Core template loop fallback.
